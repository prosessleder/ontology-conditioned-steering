# Independent adversarial review of the protocol release

**Review date:** 9 October 2026. **Scope:** the current manuscript, hypotheses, protocol, ontology versions, generator, prompts, evaluator, analysis, and inference runner. This review was conducted separately from manuscript drafting by the literature-review agent. It is an internal adversarial review, not external peer review, expert certification, or evidence of model effectiveness.

## Verdict

The release can be presented honestly as a **research-protocol preprint and reproducibility package**. It cannot yet be presented as a completed experimental paper, demonstration of successful ontology control, or established novel algorithm. The paper consistently discloses pending model experiments and limits the originality claim to a candidate benchmark/protocol combination. The adversarial literature audit defeats the broad firstness claims and identifies direct competitors. No inspected exact match to the complete evaluation combination was located; this remains bounded evidence.

The design now makes its primary causal comparison interpretable: C+V and C receive identical context, outcomes require useful execution on feasible cases, the ontology transition is precisely specified, and vector selection is frozen before test. Several validity threats remain important before an empirical interpretation can be supported. Some are acknowledged follow-ups rather than implemented controls. A deposit of the protocol should preserve that distinction.

## Concrete dataset diagnostics

A read-only reconstruction using the default seed and latest generator confirmed 720 cases, 240 in each split. Each split contains 192 core cases and 48 adaptation cases. Its primary extraction pool contains 24 pairs per version, with 12 pooled instances each of prohibited-operation substitution, unknown-operation substitution, wrong class, and wrong order. Compatible and incompatible endpoints preserve the same status and membership fields; default label-token differences are therefore not the immediate confound. Half the pool retains operation identities, providing partial controls against a banned-word explanation.

The test split contains 24 ordinary feasible cases per version and 12 V2 temporal feasible cases. The temporal feasible cases all belong to one structural family. V2 temporal infeasibility covers energy, mass cap, living targets, and no keeper: nine cases per type in the full dataset and three per type in test. Unknown test requests include `shadow_weave` (16), `song_binding` (16), `echo_matter` (16), and V1 `rewind_local` (24). These counts are dataset properties, not generated-model outcomes. More instances of those same structures do not create new independent families.

The primary common-support pool intentionally has no compatible temporal examples. This makes H3 a demanding test of whether changed rule context alone changes the extracted ordinary-plan direction enough to affect temporal use. A failure would be unsurprising and informative about this recipe. The extended pool adds V2 temporal demonstrations and changes sample size/composition; improvement there needs that alternative interpretation. Neither implementation automatically compiles arbitrary rule changes into a validated intervention.

## Implementation and measurement gates

Before interpreting a measured effect, retain evidence for intended hook positions, zero-coefficient equivalence, hook cleanup, finite nonzero directions, cached generation, and preserved prompt equality. These establish the tested intervention rather than its semantic meaning. Keep vector/model/ontology/source hashes and full output records. Reject incomplete condition pairing; avoid silently excluding failed cases. The analysis implementation already checks paired provenance and missing metrics.

The current software tests and independent source checks support an auditable protocol release. They do not establish target-model throughput, peak memory, steering capability, meaningful unsteered interference, power for a 5-point margin, or reliability beyond the supplied cases. Those remain measured-study gates.

## Permitted conclusion language

For this release: “We release a prospective causal-ontology version-transition benchmark and matched activation-steering protocol. Direct predecessors limit the candidate contribution to this evaluation combination. Model experiments are pending.”

For a later positive experiment: identify the exact model, context, extraction policy, layer, magnitude, families, and observed effect with harms and uncertainty. Improvement under those settings supports a scoped behavioral causal effect. It does not establish internal concept deletion, a universal ontology compiler, guaranteed containment, or original invention of activation steering. A result that only beats the stale vector is evidence of stale-intervention damage and recovery unless it also exceeds prompt-only C.

For a later null experiment: preserve it, disclose technical/ceiling limitations, and avoid claiming impossibility for other intervention sites, estimators, conditional methods, or nonlinear representations. Useful benchmark evidence does not require a steering success.
